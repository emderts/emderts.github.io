# 한국어 번역 규칙 (소유자 확인 2026-11-21)

- 문체: **-합니다**.
- 용어: `glossary_ko.json`(소유자 용어집)을 따른다. 용어집에 없는 것은 아래 표.
- **You** = "당신". 효과 문구에 있는 You는 가능한 한 살린다.
- **may** = "-해도 됩니다".
- **test** = "테스트". **positive / negative**(토큰) = "긍정적 / 부정적".
- 아이콘 표기(`[Heat]` 등)도 번역한다: `[열기]`.
- 외국어(독일어·라틴어·이탈리아어·프랑스어) 고유 이름: "음차 - 풀어낸 뜻".
- Lux = 광휘, Tenebrae = 암영, Luxfire = 광휘의 화염. Bog = 수렁, Quag(mire) = 진펄, Swamp = 늪, Marsh·Fen = 습지, Mire = 진창, Slough = 진구렁, Morass = 늪지대.
- Mob = 개체. Graal = 그랄. Toxified(Condition) = 맹독.

| 원문 | 번역 |
|---|---|
| Evasion / Precision / Speed / Potential | 회피 / 정확도 / 속도 / 잠재력 |
| Armor die / Power die | 방어 주사위 / 위력 주사위 |
| Hit / Wound | 명중 / 부상 |
| Condition card / Technique / Squire | 상태 카드 / 기술 / 종자 |
| Hand Limit / Choke Limit / Poison Limit | 손패 한계 / 질식 한계 / 독 한계 |
| Move action / Attack action / free action | 이동 행동 / 공격 행동 / 자유 행동 |
| active ability | 활성 능력 |
| Gated Effects | 조건부 효과 |
| Oubliette / Bargain / Mettle deck | 지하감옥 / 거래 / 기개 덱 |
| Rear space / Knight Board | 후방 칸 / 기사 보드 |
